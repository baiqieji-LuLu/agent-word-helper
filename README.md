# agent-word-helper
A Python-based CLI tool for creating and reading Word DOCX documents without Microsoft Word or COM automation. It supports Markdown-to-DOCX formatting, native OMML math equation generation from LaTeX, and extraction of text and tables from existing DOCX files.
Designed for AI Agents and automated document workflows, the tool uses python-docx and OOXML to avoid Word COM automation dependencies. Mathematical formula conversion is implemented through a LaTeX → MathML → OMML pipeline and requires an external XSLT stylesheet.

Why does this project exist?
If you are building AI Agents or automated workflows that interact with Word documents, you've probably suffered from these two issues:
The COM Interface Crashes: When an Agent silently invokes local Windows Word via win32com, it frequently crashes with "Word cannot create the work file" or triggers endless permission pop-up errors due to sandbox restrictions or orphaned processes.
Formula Disasters: The mathematical formulas generated by your LLM end up as garbled text, uneditable Unicode characters, or blurry images when inserted into Word.
word_helper.py is a black-box CLI tool built to solve exactly these problems.

Features
No Word COM Dependency: Create and read DOCX files without launching Microsoft Word, avoiding COM-related automation failures.
Native OMML Formula Rendering: Features a built-in LaTeX -> MathML -> OMML pipeline. Just pass standard $...$ or $$...$$, and it outputs native, double-click-editable Word math formulas.
Markdown to Docx: Supports common Markdown syntax (headings, lists, tables, code blocks) with built-in standard styling (A4, Chinese fonts support, etc.).
Bi-directional: Not only can it generate documents, but it can also extract pure text and tables from existing .docx files for your Agent to read.

Installation
Clone this repository.

Install dependencies:

pip install python-docx latex2mathml lxml

###IMPORTANT###: Ensure MML2OMML.XSL (included in this repo) is placed in the same directory as word_helper.py. This stylesheet is required for converting MathML to OMML.

Prerequisite: MML2OMML.XSL
To convert MathML to OMML, this tool requires Microsoft's official MML2OMML.XSL stylesheet. Due to copyright restrictions, this file is not included in this repository.
How to get it:
If you have Microsoft Office installed on Windows, search for MML2OMML.XSL in your Office installation directory (usually located at C:\Program Files\Microsoft Office\root\Office16\).
Copy the file and place it in the same directory as word_helper.py.
If you do not have Office installed, you can search for this file online or extract it from an Office ISO.

Quick Start
1. Create a document from a string (with formulas):

python word_helper.py create --text "Energy conservation: \$E=mc^2\$" -o output.docx --format markdown

2. Create a document from a Markdown file:

python word_helper.py create notes.md -o notes.docx --format markdown

3. Read text and tables from a document:

python word_helper.py read output.docx

Built for AI Agents
This repository includes a ready-to-use AGENT_GUIDE_WORD.md.
When you are prompting your LLM Agent (Claude, GPT, DeepSeek, etc.), simply inject this guide into the system prompt. It will strictly command the Agent to use this script instead of hallucinating win32com code, saving you hundreds of thousands of tokens and preventing endless debugging loops.
